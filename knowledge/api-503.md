# API 503 responses

**Symptoms:** callers receive HTTP 503, often immediately after a release.

**Investigate:** compare deployment time with the first error, inspect readiness and dependency health, and verify whether the service has capacity.

**Safe actions:** pause rollout or prepare a rollback for operator confirmation. Do not execute a rollback automatically.

**Warnings:** a 503 can be an intentional overload response; confirm health signals before changing production.
